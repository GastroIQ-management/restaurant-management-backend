| Expected context | `AuthController` reads and writes the token only through `RefreshTokenCookie` (`Read`, `Write`, `Clear`, `ClientOf`) and returns `SessionResult.Auth`. `SessionService` takes the token as a string and is source-agnostic: rotation, reuse, idle (7 days), 30-day limit, deactivated user and removed member stay as they are, with no service change.
