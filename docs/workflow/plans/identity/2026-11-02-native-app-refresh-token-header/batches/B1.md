## T1 — Native origins setting, checked at startup
| Field | Value |
|---|---|
| Expected context | No native mode exists. Identity options follow `InvitationOptions` / `InvitationOptionsValidator` (`src/RestaurantManagement.Modules.Identity/Services/Invitations/`), bound and validated at startup in `src/RestaurantManagement.Web/Program.cs` (`AddOptions().Bind().ValidateOnStart()` plus an `IValidateOptions` singleton). `Services/Sessions/` already holds 11 files, so a new file there is blocked by `.claude/hooks/enforce-structure.py`: the options go in a new feature subfolder `Services/NativeApps/`. | Outcome | #7: a web origin can never be configured as native. Verified by validator unit tests, a startup test and a shipped-value test |
