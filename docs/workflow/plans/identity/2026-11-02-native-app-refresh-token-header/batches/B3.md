## T4 — Header token kept out of error reports
| Field | Value |
|---|---|
| Expected context | Sentry (error tracking service) is set up in `src/RestaurantManagement.Web/Hosting/SentryHostingExtensions.cs` with no event filter. Sentry's ASP.NET Core integration can attach request headers to events, and a custom header such as `X-Refresh-Token` is not treated as sensitive by default. `ExceptionHandlingMiddleware` logs only the exception and a fixed message; `SessionService` errors carry localized text, never the token |
