## T1 — Shared version mapping, version check and `version.conflict` 409
| Field | Value |
|---|---|
| Expected context | No entity has a concurrency token (no `IsConcurrencyToken`, `[Timestamp]`, `xmin` or `DbUpdateConcurrencyException` handling in `src/`). Errors are a `BusinessException(ErrorCode, message)` written by `ExceptionHandlingMiddleware` through `ProblemResponse.WriteAsync` (RFC 9457 Problem Details with `code` and `traceId`); codes live in `ErrorCodes` (Shared catalog, listed in the OpenAPI document by `ErrorCodesDocumentFilter`); titles are localized in `SharedResource.resx`, `.pt.resx`, `.fr.resx`. Module unit tests run on SQLite in-memory (`EnsureCreated`), where `xmin` does not exist, so the mapping must keep those databases building and saving. `Shared/Data/` is grouped in subfolders, so new files go in a new `Data/Versioning/` subfolder |
| Expected result | (1) An entity marked as versioned has a `uint Version` that EF Core (Entity Framework Core) maps to PostgreSQL `xmin` as a row version (read back after every insert and update, never stored as a column); on any other provider it is a plain concurrency token so SQLite tests keep working. (2) One reusable check takes a loaded entity and the version the client sent: a different version throws the version conflict; an equal one becomes the original value, so a save that loses a race (`DbUpdateConcurrencyException`) also ends as the version conflict. (3) `ErrorCodes.VersionConflict` = `version.conflict`, 409, not a retry code, with a translated title (en, pt, fr). (4) A version conflict exception carries the current record (any response model); the middleware writes the usual problem answer plus `current` holding that record, and nothing else about it |
| Outcome | #1, #4, #5 groundwork; verified by unit tests in `tests/RestaurantManagement.Shared.Tests/` (check: stale throws, equal passes; middleware: 409, code `version.conflict`, translated title, `current` present) and one PostgreSQL test in `tests/RestaurantManagement.Web.Tests/Shared/` that a versioned row's version changes on update and a save with the old version fails |
